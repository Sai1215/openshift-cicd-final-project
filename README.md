# OpenShift CI/CD Final Project

A sample Python application demonstrating continuous integration with GitHub Actions and Tekton task definitions for OpenShift Pipelines.

## Project structure

- `app.py` — small Flask application with a health endpoint.
- `tests/test_app.py` — unit tests using nose.
- `.github/workflows/workflow.yml` — flake8 linting and nose tests.
- `.tekton/tasks.yml` — cleanup and nose test tasks for OpenShift Pipelines.

## Run locally

```bash
python -m pip install -r requirements.txt
flake8 app.py tests
nosetests -v
python app.py
```

The application listens on port 8080 by default.

## GitHub Actions

Pushes and pull requests to `main` run the lint and unit-test jobs. Open the Actions tab to inspect the run and save the successful-run terminal/log evidence required by your course.

## OpenShift Pipelines

The Tekton file defines a workspace-based cleanup task and a nose test task. Apply it in a course-provided OpenShift project with:

```bash
oc apply -f .tekton/tasks.yml
oc get tasks
```

Create the PVC and Pipeline/PipelineRun resources required by your course lab before collecting the PVC and pipeline screenshots. Exact PVC size, storage class, and pipeline name can depend on the cluster and course instructions.
